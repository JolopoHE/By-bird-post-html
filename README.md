# 鳥鳥傳信（BirdMail）

飛鴿傳書主題的限時留言網頁：寫一封信交給小鳥，讓它飛到某個陌生人的窗前。

靈感來自 IG 限時動態的「限時、低壓力」。使用者寫下的信由小鳥隨機送到陌生人的頁面，對方可以拆信、收藏、按讚或回信。信有壽命，會隨時間泛黃、出現污漬和缺角，最後被風吹走；別人的回應可以替它續命。整個畫面是俯視角的像素風場景，所有美術都由程式繪製。

## 怎麼執行

不需要安裝任何東西，**直接雙擊 `index.html`** 用瀏覽器開啟即可（只做電腦版）。

- 資料目前是假資料（`data.js`）＋ localStorage，還沒接後端。
- 別人的讚與回信是模擬的（`api.js` 的 `SIM_FEEDBACK`）。
- 想從頭體驗（包含歡迎信），清掉瀏覽器中此頁的 localStorage 即可。

## 使用

- **寄信**：麻雀送純文字信封、鴿子送附圖片的明信片、貓頭鷹送裝著大型檔案的牛皮紙包裹。
- **收信**：小鳥把別人的信隨機送到收信區，可以拆信、存進存信箱（永久保留，上限 100 封），或用掃帚一次掃掉。
- **壽命**：信從寄出開始變老，依序泛黃、出現污漬、缺角，最後被風吹走；按讚、回信可續命。
- **回應**：回信或按讚要由休息區的鳥叼走，沒鳥時可以撒飼料把牠們引來。寄出的信收到回應時，郵箱會舉起旗子，鳥台上也會有鳥等著。
- **私人傳書**：輸入對方的鳥號一對一寫信，這種信沒有壽命。
- **我的鳥巢**：個人頁，可設定頭像與暱稱，看統計與蛋圖鑑（偶爾來訪的環頸斑鳩會留下彩蛋）。
- **檢舉**：讀信與私人傳書畫面都有檢舉入口，為之後的內容審核預留。

## 檔案結構

| 檔案 | 說明 |
|---|---|
| `index.html`、`style.css` | 畫面與樣式（舞台 1920×1080 等比縮放） |
| `main.js` | 互動邏輯；畫面與手感設定集中在檔案最上方 |
| `api.js` | 資料存取層 `window.BirdAPI`（目前是 localStorage＋假後端，之後換成 fetch 只改這層） |
| `data.js` | 假信件 |
| `assets/` | 像素圖（由 `tools/make_sprites.py` 產生） |
| `tools/make_sprites.py` | 美術產生器，需要 Python 3 + Pillow：`python tools/make_sprites.py` |

## 技術特色

- 純 HTML／CSS／JavaScript，沒有框架、沒有建置工具。
- DOM 分層的場景，鳥的移動與信件壽命由前端狀態機與計時邏輯驅動。
- 像素圖全部由 Python 腳本逐格繪製；音效用 Web Audio 即時合成，沒有音檔。
- 資料存取集中在 `api.js`，統一回傳 Promise，失敗時 reject `{ code, message }`。
